1The decision — and what the qualitative work found

If nothing would be done differently depending on the answer, the survey is not worth running. Write the decision first, then who you will ask. A survey usually comes AFTER qualitative work, so add what your interviews or focus groups surfaced — the patterns the survey will test at scale.

2What you need to learn → analysis → scale

Start with three; add more if a decision really needs them. For each line, choose the analysis it will end in — and the line underneath tells you the scale level the question must use (nominal, ordinal, interval or ratio) and how to write it. This is 5.4: the analysis decides the scale, so decide the analysis first. A line with no analysis does not become a question.

The rule behind this stepEvery question maps to one concept you need to learn, one analysis and therefore one scale level. If you cannot name the analysis, the question is not ready. Pick the highest scale the concept honestly supports — no higher.

The scale IS the decision (5.4)Choose the level each question needs: NOMINAL (a list, for frequencies), ORDINAL (a rank, for the median), INTERVAL (a balanced labelled rating, for the mean and the t-test) or RATIO (a number with a true zero). Pick the highest the concept honestly supports, no higher — you can always collapse a rating into bands later, but you can never recover detail you did not ask for. Ratings are balanced and labelled at every point, always in the same direction.
